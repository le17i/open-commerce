# Codebase Index

Index of actual service (business-logic) functions per domain, generated by reading the code — regenerate/update this when a service's methods change. Method shapes here are what new code should imitate for that domain.

## catalog

Common CRUD shape across `brand`, `category`, `color`, `kind`, `product`: `create(...)`, `find(predicate, initial = 0, perPage = 20)`, `findById(id)`, `findOne(predicate)`, `update(predicate, model)`.

| Domain | Notable methods | Notes |
|---|---|---|
| `product` | `create(title, slug, sku, barcode, model, brandId, categoryId, colorId, kindId, content?, description?, height?, length?, parentId?, price?, stock?, weight?, width?, status?)`, `find`, `findById`, `findOne`, `update(predicate, model)`, `addImage(productId, ext, filename, description?)` | Creates an initial `Offer` alongside the product. Positional-arg legacy pattern — see [DATA_LAYER.md](DATA_LAYER.md) for the object-param convention for new methods. |
| `product-offer` | `ProductOffersService` — see `services/catalog/src/product/product-offer.service.ts` | |
| `brand` | `create`, `find`, `findById`, `findOne` | No `update`/`delete` yet |
| `category` | `create`, `find`, `findById`, `findOne`, `update()`, `delete()` | ⚠️ `update`/`delete` are present but stubbed empty — implementing these is open work |
| `color` | `create`, `find`, `findById`, `findOne` | No `update`/`delete` yet |
| `kind` | `create(label, code)`, `find`, `findById`, `findOne` | No `update`/`delete` yet |
